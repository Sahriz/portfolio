# DroneSim

> ⚠️ This repository doesn't have a README on GitHub yet. This page is a stub — once a real README is pushed to the repo, it can replace this file.

Autonomous drone navigating procedurally generated terrain in C++ / OpenGL. A control loop steers the drone through the simulated environment in real time.

## Tech stack

- **Language:** C++
- **Graphics:** OpenGL with GLSL shaders
- **Build:** CMake
